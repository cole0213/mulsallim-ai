# 물살림 AI MVP

제3회 KRC AI 디지털 혁신 공모전 서비스개발 분야 제출용 웹 MVP입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 배포 전에는 GitHub Pages, Netlify 또는 Vercel에 정적 파일 그대로 올릴 수 있습니다.

## 현재 범위

- 전남 시범 권역 저수지 6곳의 위험 우선순위 UI
- 수위·평년 대비·강수량 기반 안전일 카드
- 농민/관리자별 행동처방
- 설명 가능한 AI 산출 방식 안내

현재 카드 데이터는 화면 시연용 예시입니다. 실제 제출 전에는 아래 공공데이터를 수집해 `app.js`의 `reservoirs` 데이터를 API 응답으로 교체해야 합니다.

- 한국농어촌공사_농촌용수 저수지 수위정보 조회
- 한국농어촌공사_가뭄지도 정보
- 기상청 단기예보 및 강수량 정보

## 정직한 제출 원칙

실제 API 연동 전에는 화면·발표자료에 `KRC 공공데이터 기반 시연 데이터`라고 표기합니다. 실제 데이터 연동·검증 이후에만 예측 정확도나 실시간 서비스라는 표현을 사용합니다.
