물살림 AI · 모델카드

TRANSPARENCY BEFORE AUTOMATION

‘예측’보다 먼저, 확인 가능한 근거를 제공합니다.

물살림 AI는 KRC 공개 저수지 수위정보를 바탕으로 변화 신호와 현장 확인 우선순위를 보여주는 의사결정 보조 서비스입니다. 자동 급수·공식 가뭄 경보·행정 처분을 수행하지 않습니다.

1. 현재 배포 기능

설명 가능한 전환 신호최신 저수율, 7일 변화, 관측 연속성의 근거를 화면에 함께 표시합니다.
현장 행동 제안위험 신호가 있으면 관측 재확인·급수 전환 검토 등 ‘다음 확인’ 중심으로 안내합니다.
지역 기반 조회시·도와 시·군·구를 선택하면 이용자가 저수지 코드를 알 필요 없이 KRC 데이터로 연결됩니다.
협의 카드개인정보 없이 같은 근거와 현장 확인 상태를 30일간 공유합니다.

2. 검증한 것과 배포에서 제외한 것

오프라인 탐색탑정저수지 365일 관측 이력으로 Isolation Forest 기반 전환 패턴 탐색을 수행했습니다. 입력은 저수율, 7일 기울기, 일별 변동성입니다.
탐색 결과의 의미최근 패턴이 해당 저수지의 과거 패턴 중 얼마나 드문지 확인하는 보조 근거입니다. 가뭄 발생이나 미래 저수율을 예측하는 모델이 아닙니다.
예측 모델 평가7일 후 저수율 예측 후보는 기준선보다 성능이 낮아 배포에서 제외했습니다. 성능 미달 모델을 화면의 ‘AI 예측’으로 표현하지 않습니다.
현재의 안전장치공식 경보를 대체하지 않음, 자동 의사결정 금지, 원자료·관측일 표시, 현장 확인 후 사람의 상태 갱신을 적용합니다.

중요: 이 서비스의 위험 단계는 현장 점검 우선순위입니다. 농업용수 공급·급수 전환·공식 가뭄 판단은 KRC 및 관계기관의 공식 절차와 현장 확인을 따라야 합니다.

3. 다음 검증 게이트

데이터 확장저수율 외 강수, 유역·수요, 급수·가뭄 이력 등 시계열을 결합하고 지역·계절별 누수를 막습니다.
시간 분리 검증과거 학습·미래 검증을 엄격히 분리하고, 기준선 대비 정밀도·재현율·오경보율을 공개합니다.
현장 파일럿실제 확인 카드의 확인 완료율, 행동까지 걸린 시간, 불필요 경보율을 측정합니다.
배포 기준사전 정의한 성능 기준을 충족할 때만 예측 기능을 제한적으로 추가하고, 미달이면 계속 보류합니다.
