# 물살림 AI 사용성 인터뷰·파일럿 운영 키트

## 목적

이 문서는 성과를 만들기 위한 설문이 아니라, 서비스가 농업인과 현장 담당자의 판단을 실제로 돕는지 검증하기 위한 운영 도구다. 불리한 의견도 원문 그대로 기록하고 개선 항목으로 반영한다.

## 참여자와 운영 원칙

- 권장 표본: 농업인·수리계 5명 이상, KRC/지자체 현장 담당자 3명 이상.
- 사전 고지: 이름·전화번호·정확한 농지 주소·민감한 영농 정보는 서비스와 설문에 적지 않는다.
- 세션 시간: 20~30분. 진행자는 정답이나 사용 방법을 먼저 알려주지 않는다.
- 기록 원칙: 참여자 역할만 분류하고, 발언은 익명 번호(`F-01`, `O-01`)로 기록한다.
- 금지: “좋았다”는 답을 유도하거나, 미완성 파일럿을 완료 성과처럼 발표하는 것.

## 1. 사전 질문 (3분)

1. 평소 농업용수·저수율 정보는 어디서 확인하나요?
2. 저수지 수치가 낮거나 갑자기 바뀌었을 때 누구와 어떤 순서로 확인하나요?
3. 저수지 코드나 행정구역·저수지명 검색에서 어려웠던 점이 있나요?

## 2. 과업 시나리오 (12분)

진행자는 “우리 지역의 농업용수 상황을 확인하고, 필요하면 다른 사람과 확인할 일을 공유해 달라”고만 안내한다.

| 과업 | 성공 기준 | 관찰 기록 |
|---|---|---|
| 시·도와 시·군·구 선택 | 도움 없이 지역 목록에 도달 | 시작·완료 시각, 막힌 지점 |
| 저수지 선택 | 코드를 입력하지 않고 원하는 저수지 선택 | 선택 경로, 혼동한 명칭 |
| 변화 이해 | 최신 관측일·저수율·7일 변화를 자기 말로 설명 | 설명 정확성, 오해 문장 |
| 다음 행동 판단 | 화면 근거를 보고 확인할 일을 하나 선택 | 선택한 행동, 이유 |
| 협의 카드 | 개인정보 없이 확인 카드를 생성·공개 링크 의미 설명 | 공개/관리 권한 이해 여부 |

## 3. 사후 질문 (5분)

1. 이 화면에서 가장 먼저 봐야 할 정보는 무엇이라고 이해했나요?
2. 위험 단계가 공식 경보가 아니라 ‘현장 확인 우선순위’라는 점이 분명했나요?
3. 다음 관측일에 다시 사용할 이유 또는 사용하지 않을 이유는 무엇인가요?
4. 실제로 쓰려면 꼭 추가돼야 할 정보나 연결 기능은 무엇인가요?
5. 불필요하거나 신뢰하기 어려운 부분은 무엇인가요?

## 4. 정량 KPI 기록표

| 지표 | 산식 | 성공 판정 예시 |
|---|---|---|
| 첫 결과 도달 시간 | 지역 선택 시작 → 저수지 결과 화면 | 중앙값 2분 이내 |
| 과업 성공률 | 도움 없이 완료한 과업 / 전체 과업 | 80% 이상 |
| 근거 이해도 | 관측일·변화·주의문을 정확히 설명한 참여자 비율 | 80% 이상 |
| 협의 카드 권한 이해 | 공개 읽기 / 생성자 상태 변경을 정확히 구분한 비율 | 80% 이상 |
| 재사용 의향 | 파일럿 화면 4~5점 응답 비율 | 표본 수와 함께 제시 |
| 개선 발견 수 | 중복 제외, 실행 가능한 불편·오해 항목 수 | 수치가 많아도 실패가 아니라 개선 근거 |

## 5. 4주 파일럿 운영표

| 주차 | 활동 | 산출물 |
|---|---|---|
| 0주 | 참여자 모집·개인정보 고지·사전 인터뷰 | 역할별 익명 ID, 기준 업무 흐름 |
| 1주 | 첫 사용성 세션·핵심 오류 수정 | 과업 기록, 개선 목록 |
| 2~3주 | 실제 관측 갱신에 맞춰 지역 조회·협의 카드 사용 | 카드 생성/확인 완료, 익명 피드백 집계 |
| 4주 | 회고 인터뷰·KPI 계산·개선 우선순위 결정 | 결과표, 원문 요약, 미달 지표와 원인 |

## 발표·제출 시 표현 규칙

- 응답이 8명 미만이면 “초기 탐색 결과”라고만 쓴다.
- 표본 역할·기간·중도 이탈·불편 의견을 함께 공개한다.
- KPI 목표와 실제 결과를 혼동하지 않는다.
- AI 모델 성능과 사용성 점수를 하나의 ‘정확도’로 합치지 않는다.
