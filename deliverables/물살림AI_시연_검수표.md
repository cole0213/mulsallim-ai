# 물살림 AI 심사 시연 검수표

## 사용법

발표 직전, 발표자와 보조자가 아래 항목을 순서대로 확인한다. 오류가 나면 예시 데이터로 대체하지 말고 KRC 원자료 재조회 또는 준비한 실제 관측 화면으로 설명한다.

## 1. 시작 전

- [ ] `http://localhost:4182/api/health`에서 `krcConfigured: true` 확인
- [ ] 랜딩 `mulsallim-home.html` 열림
- [ ] 실제 대시보드 `mulsallim-action.html` 열림
- [ ] API 인증키가 주소창·개발자도구·화면에 보이지 않음
- [ ] ADMS 공식 예경보 비대체 문구가 첫 화면과 대시보드에 표시됨

## 2. 지역 탐색

- [ ] 시·도를 선택하면 시·군·구 선택지가 갱신됨
- [ ] 시·군·구 선택 후 저수지 찾기를 누르면 후보가 표시됨
- [ ] 시설 코드가 화면에 표시되지 않음
- [ ] 후보가 없으면 다른 지역 데이터를 대신 보여주지 않고 안내함
- [ ] 강원특별자치도·제주특별자치도도 선택 가능함

## 3. 판단 근거

- [ ] 저수지를 고르면 최신 관측일·저수율·수위가 표시됨
- [ ] 30·60·90일 전환이 동작함
- [ ] 그래프 Y축 저수율, X축 날짜, 관심 50%, 주의 35% 선이 보임
- [ ] 관측점 위에 마우스를 올리면 날짜·저수율·수위가 표시됨
- [ ] 데이터 건수·누락일·신뢰도가 표시됨
- [ ] AI 전환 신호의 근거 카드 네 개가 표시됨

## 4. 행동 기능

- [ ] 관심·주의선 도달 추정이 최근 하락 추세 가정임을 확인
- [ ] 작물·생육 단계·면적을 바꾸면 참고 용수 수요가 갱신됨
- [ ] 0·10·20% 절수 지연 효과에 탐색 가정 문구가 표시됨
- [ ] 같은 지역 비교에서 전환 신호 순위가 표시됨
- [ ] 관심 저수지 저장 버튼이 동작함
- [ ] 브리핑 복사 또는 TXT 저장이 동작함

## 5. 책임 있는 AI

- [ ] 후보 Gradient Boosting이 기준모델보다 낮아 배포 제외됐다는 내용 표시
- [ ] MAE·MAPE 수치가 서버 검증 결과와 일치
- [ ] “공식 경보·급수 지시를 대체하지 않는다”는 문구 확인

## 6. 발표 대체 경로

| 상황 | 대응 |
| --- | --- |
| KRC API 일시 오류 | 오류 메시지를 숨기지 않고 API 상태·원자료 의존성을 설명한 뒤, 준비한 직전 관측 화면으로 시연 |
| 해당 지역 후보 없음 | KRC 원자료가 해당 세부 지역을 제공하지 않는다는 안내를 보여 주고, 미리 선정한 시범 지역으로 전환 |
| 하락 추세가 아닌 회복 추세 | 억지로 위기라고 하지 않고 안정 판정이 나오는 것이 데이터 기반·과장 없는 서비스의 증거라고 설명 |
| 절수 효과 질문 | 확정 예측이 아니라 순감소 속도 가정의 협의 도구이며, 현장 수요·기상·유입량을 추가 확인한다고 답변 |
