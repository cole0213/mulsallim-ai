## C. 추진배경

### 1. 문제 인식

기후변화에 따른 가뭄과 국지성 강우의 반복은 농업용수 공급의 불확실성을 높이고 있다. 농업용 저수지 수위와 저수율 정보는 공개되어 있으나, 수치 자체만으로는 농민이 자신의 관개 일정을 조정하거나 담당자가 현장 점검의 우선순위를 결정하기 어렵다.

예를 들어 저수율이 40%라는 정보는 현재의 저장 상태를 알려주지만, 해당 수치가 평년과 비교해 어느 수준인지, 최근에 얼마나 빠르게 하락했는지, 단기 강수로 회복될 가능성이 있는지, 사용자가 언제 절수해야 하는지를 직접 알려주지 못한다.

### 2. 서비스 필요성

농업용수 데이터는 단순 조회를 넘어 현장 의사결정을 지원하는 형태로 전환될 필요가 있다. 물살림 AI는 다음의 정보 격차를 해결한다.

- 농민: 저수율 수치를 실제 관개·절수 판단으로 해석하기 어려움
- 담당자: 다수 저수지를 매일 확인하며 위험 지역을 선별해야 함
- 일반 국민·귀농 예정자: 지역별 농업용수 리스크를 이해하기 어려움

### 3. 시장 및 경쟁 환경

기존 농업용수·가뭄 정보 서비스는 저수율·수위·가뭄 현황을 제공하는 데 중점을 둔다. 물살림 AI는 기존 데이터를 대체하지 않고, 이를 조합·해석하여 행동 가능한 정보로 제공한다. 즉, `현황 조회 서비스`가 아니라 `농업용수 의사결정 지원 서비스`를 지향한다.

## D. 주요내용

### 1. 서비스 구성

물살림 AI는 랜딩 페이지와 운영 대시보드로 구성된다.

| 화면 | 주요 기능 | 사용자 가치 |
|---|---|---|
| 서비스 소개 | 서비스 목적·안전일 산출 원리 안내 | 서비스 신뢰성 이해 |
| 권역 현황 | 평균 안전일, 위험 저수지 수, 평균 저수율, 단기 강수량 | 권역 전체 위험 빠른 파악 |
| 저수지 관제 | 검색·상태 필터·위험도 정렬 | 우선 점검 대상 선별 |
| 저수지 상세 | 최근 수위 추세, 위험 근거, 농민·관리자 처방 | 근거 기반 판단 |
| 관개 처방 | 작물·생육 단계·면적에 따른 시뮬레이션 | 영농 의사결정 보조 |
| 점검표 내보내기 | 주의 저수지 및 권장 조치 파일화 | 현장 업무 연계 |

### 2. 농업용수 안전일

`안정 관개 가능일`은 현재 저수율, 평년 대비 저수율, 최근 수위 하락 속도, 향후 강수량, 지역 가뭄 단계를 종합해 산출하는 의사결정 보조지표이다.

사용자는 기존의 원시 수치 대신 아래와 같은 결과를 확인한다.

- 안정: 현재 관개 계획 유지 및 정기 확인
- 관심: 계획 급수량 조정 준비 및 수위 추이 확인
- 주의: 절수 전환 검토 및 우선 현장 점검

안전일은 공식 가뭄 경보나 자동 관개 명령이 아니며, 사용자의 판단을 돕기 위한 보조 정보임을 명확히 표시한다.

### 3. 설명 가능한 위험 분석

서비스는 위험 단계만 표시하지 않고, 판단에 영향을 준 항목을 함께 제공한다.

예시: `평년 대비 저수율 -18%p`, `최근 7일 저수율 하락`, `향후 3일 누적 강수량 4mm`와 같이 위험 근거를 공개한다. 이를 통해 사용자는 결과를 검토할 수 있고, 담당자는 점검 필요성을 설명할 수 있다.

### 4. 사용자별 행동지침

농민 화면은 관개·절수·재확인 시점처럼 실천 가능한 문장으로 제공한다. 담당자 화면은 우선 점검 대상, 수위 급감 여부, 대체 수원 확인 등 관리 업무 중심의 지침을 제공한다.

## E. AI·데이터 활용성

### 1. 공공데이터 활용 범위

한국농어촌공사 저수지 수위정보 조회 데이터에서 저수지별 수위·저수율·관측시각을 활용한다. 가뭄지도 정보에서는 평년저수율, 가뭄 단계, 유효저수량, 수혜면적 등 지역 단위 위험 분석 항목을 활용한다. 기상청 단기예보에서는 향후 강수량을 수집해 단기 회복 가능성을 반영한다.

### 2. AI 및 분석 구조

MVP는 데이터 근거를 명확히 보여줄 수 있는 규칙 기반 복합 위험점수로 시작한다. 위험점수는 저수율 위험, 평년 대비 편차 위험, 최근 하락 추세 위험, 단기 강수 부족 위험, 가뭄 단계 위험을 합산하여 산출한다.

실서비스 단계에서는 과거 일 단위 수위 이력이 확보된 경우 시계열 예측 모델을 적용해 7일·14일 위험도를 고도화하고, 인근·과거 패턴과 비교하는 이상탐지 모델로 급격한 수위 변화를 점검한다.

생성형 AI는 위험점수를 직접 산출하지 않는다. 검증된 분석 결과를 농민과 담당자가 이해하기 쉬운 행동지침으로 변환하는 보조 역할만 수행한다.

### 3. 데이터 신뢰성 관리

- 관측시각이 오래된 데이터는 갱신 지연 상태로 표시
- 저수율 범위 오류와 결측값은 분석에서 제외 후 데이터 부족으로 안내
- API 장애 시 마지막 성공 데이터의 기준시각 표시
- API 인증키는 백엔드 환경변수에만 저장하고 브라우저에 노출하지 않음

## F. 추진성과 및 기대효과

### 1. 정량적 기대효과

- 위험 저수지 자동 우선순위화로 일일 모니터링·선별 업무 부담 완화
- 수치 조회에서 행동지침 제공으로 전환하여 현장 대응 판단 시간 단축
- 절수 시점의 사전 인지를 통한 불필요한 용수 사용 감소 기대

### 2. 정성적 기대효과

- 공공데이터를 농민이 이해하기 쉬운 서비스 언어로 전환
- 담당자의 현장 점검·대체 수원 검토를 지원하는 데이터 기반 업무 보조
- 농업용수 정보에 대한 국민 접근성과 이해도 향상
- 향후 농촌용수종합정보시스템·농업가뭄관리시스템과 연계 가능한 확장성 확보

### 3. 서비스 고도화 방향

저수지별 과거 일 단위 수위·급수량·방류량, 수혜구역 공간정보, 작물별 재배면적·용수 수요, 수질 측정 이력이 추가 연계되면 농경지·작물 단위의 맞춤형 관개 의사결정 서비스로 고도화할 수 있다.
