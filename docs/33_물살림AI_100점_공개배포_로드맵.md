## 핵심 목표

물살림 AI는 수위 정보를 예쁘게 보여주는 페이지가 아니라, 국민·농업인·현장 담당자가 **자기 지역의 물 상황을 1분 안에 이해하고 다음 확인 행동을 정할 수 있게 하는 공공 의사결정 보조 서비스**가 된다.

대상권 기준은 화면 개수나 AI라는 단어가 아니라 아래 네 가지가 동시에 증명되는 상태다.

1. 관심과 흥미: 첫 방문자가 서비스 목적과 자기 지역 진입 경로를 즉시 이해한다.
2. 미친 실용성: 지역 선택 → 저수지 확인 → 변화 근거 → 현장 확인 항목 → 협의 기록이 끊기지 않는다.
3. 신뢰 가능한 AI: KRC 원자료·판단 기준·AI 한계가 함께 보이며 성능 근거 없는 자동 경보를 하지 않는다.
4. 운영 가능한 공개 서비스: HTTPS, 비밀키 분리, 오류 복구, 접근성, 실제 사용자 피드백과 운영 지표를 갖춘다.

## 현재 실제 상태

### 완료

- KRC 농촌용수 저수지 수위정보 API를 서버에서 호출하고 저수지 코드를 노출하지 않는 지역·저수지 선택 흐름을 구현했다.
- 공개 운영 서버는 `163.152.223.16:4184`에서 Docker 컨테이너 `mulsallim-ai`로 실행 중이며 재시작 정책이 적용돼 있다.
- UFW에서 `4184/tcp`를 허용했고 외부에서 건강 상태·지역 조회·상세 수위 조회·익명 피드백 개인정보 차단을 검증했다.
- 9개 권역 18개 저수지, 6,588건 관측값으로 시간 분리 AI 검증을 수행했다. 성능 근거가 부족한 예측·자동 알림은 배포하지 않고 변화 근거와 현장 확인 보조로 한정했다.
- GitHub 공개 소스 저장소를 생성·push했다: `https://github.com/cole0213/mulsallim-ai` (`main`, 첫 커밋 `ae18e53`). `.env`, 카드·피드백 런타임 데이터, 로그는 제외한다.

### 완료 (2026-07-27 갱신 — 공개 HTTPS 배포 성공)

- **Cloudflare Pages + Functions 공개 HTTPS 배포 완료: https://mulsallim-ai.pages.dev** 에서 지역선택→저수율→AI 신호→지역 우선순위→협의까지 전 흐름 실동작 검증.
- 배포 블로커 해결: ① 생 IP는 Cloudflare가 거부(1003) → 호스트명. ② Pages CSP가 eval 차단 → 빌드에서 eval 3종을 스크립트 주입으로 대체(지역선택 복구). ③ 비표준 포트 4184 도달불가(522) → cloudflared 터널로 오리진 앞 HTTPS.
- 신기능: AI 예측 궤적 그래프 시각화(관심선/주의선 도달 시점), 지역 확인 우선순위, 오류 복구(재시도), 랜딩 물결 시그니처·대시보드 카드 뎁스·차트 크로스헤어.
- 죽은 버전 파일 102개 정리, 라이브 v12 세트만 배포. 상세: [[34_심사표_100점_자가진단_및_배포블로커_20260725]]

### 진행 중 / 미완료

- 현재 HTTPS 데이터는 로컬 cloudflared 임시 터널에 의존한다. 오리진 서버에서 named tunnel 서비스로 영구화가 필요하다.
- 실제 사용자 파일럿 수와 협의카드 완료율은 아직 0건이며 성공 지표로 주장하지 않는다.

## Pages 전환 설계

### 원칙

- 브라우저는 Pages의 고정 HTTPS 주소만 사용한다.
- KRC 키는 Pages나 GitHub에 넣지 않는다. 현재 운영 서버의 `.env`에만 둔다.
- Pages Function의 `/api/*`는 서버 간 요청으로 `http://nmlab16.korea.ac.kr:4184/api/*`를 프록시한다. **생 IP는 금지** — Cloudflare Workers `fetch()`가 raw IP subrequest를 거부(error 1003)하므로 반드시 호스트명을 쓴다(`nmlab16.korea.ac.kr` = 163.152.223.16). 기존 KRC API·카드·피드백 기능과 데이터 보관 정책을 유지한다.
- Pages 정적 자산에는 CSP, X-Frame-Options, Referrer-Policy, Permissions-Policy를 적용한다.

### 구현·배포 체크리스트

- [ ] Pages URL에서 지역 선택·수위 그래프·협의 카드·피드백·오류 응답을 검증

## 100점 기능 로드맵

### 랜딩: 관심을 행동으로 바꾸기

- 첫 화면 메시지를 “내 지역 물 상황, 지금 1분 안에 확인”으로 단일화한다.
- 시·도 → 시·군·구 → 저수지 선택을 첫 행동으로 두고 코드·전문 용어를 감춘다.
- 실제 KRC 최신 관측일과 데이터 출처를 보여 데모가 아닌 공공 데이터 서비스임을 증명한다.
- 서비스 가치(내 지역 확인, 변화 근거, 현장 협의)를 3개 카드로 압축하고 불필요한 관제 화면은 제거한다.

### 대시보드: 정보가 아니라 결정 지원

- 최신 저수율, 7일 변화, 관측일, 상태를 한 화면에 우선 배치한다.
- 그래프에는 날짜 X축·저수율 Y축·점 hover 수치·위험/주의 기준선·관측 공백을 명확히 표시한다.
- 위험은 단순 빨간색이 아니라 “왜 주의인지”, “무엇을 먼저 확인할지”, “공식 지시를 대체하지 않음”을 함께 제시한다.
- 사용자는 저수지 코드 대신 지역명과 저수지명을 보고 선택하며 URL에는 선택 지역을 보존해 공유·재방문을 쉽게 한다.

### 현장 협의·AI·접근성

- 변화 근거를 바탕으로 개인정보 없는 협의카드를 만들고 요청·확인 중·완료와 30일 보관 기한을 명시한다.
- AI는 자동 경보가 아니라 변화 후보 정렬·근거 설명·현장 확인 우선순위 보조로만 제공한다.
- 모델 카드에 데이터 범위, 시간 분리 방식, 비교 기준선, 실패 지표, 배포 제외 사유를 공개한다.
- 키보드만으로 지역 선택·그래프 설명·카드 생성이 가능하게 하고 색상만으로 위험을 표현하지 않는다.
- API 실패에는 재시도·마지막 성공 데이터 시점·공식 출처 이동 경로를 제공한다.
