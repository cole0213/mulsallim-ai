# 물살림 AI 최종 제출본 서비스 명세서

## 핵심 요약

물살림 AI는 한국농어촌공사(KRC) 농촌용수 저수지 수위 공공데이터를 국민·농업인·현장 담당자가 바로 이해할 수 있는 지역 기반 의사결정 화면으로 바꾸는 서비스다. 단순 수치 조회가 아니라 저수율, 최근 7일 변화, 위험 경계선, 관측 결측 상태를 함께 제시하고 동일 지역 비교와 작물별 절수 시나리오까지 연결한다.

## 제출 기본 정보

- 공모 분야: 서비스개발 / 안전강화
- 서비스명: 물살림 AI — 지역 농업용수 위험 판단 및 절수 협의 지원 서비스
- 최종 랜딩: `http://localhost:4182/mulsallim.html`
- 최종 실제 대시보드: `http://localhost:4182/mulsallim-dashboard.html`
- 데이터 원천: 한국농어촌공사 농촌용수 저수지 수위정보 API (`reservoircode`, `reservoirlevel`)

## 문제와 해결 방향

저수지 수위 정보는 존재하지만, 주민과 농업인은 시설 코드와 개별 수치만으로 지금의 위험도와 다음 행동을 판단하기 어렵다. 물살림 AI는 지역 선택부터 시작해 사용자가 시설 코드를 보지 않아도 관련 저수지를 찾도록 한다. 이후 관측 원자료를 추세·경계선·근거 문장으로 해석하고, 현장 협의에 필요한 비교와 절수 선택지를 제공한다.

## 사용자 흐름

1. 사용자가 시·도와 시·군·구를 선택하고 필요하면 읍·면·동 또는 저수지 이름 일부로 좁힌다.
2. 서버가 KRC `reservoircode` API에서 후보 저수지를 가져온다. 시설 코드는 서버 내부 요청에만 쓰며 화면에 노출하지 않는다.
3. 사용자가 저수지를 고르면 KRC `reservoirlevel` API에서 최근 7·30·90일 관측치를 조회한다.
4. 대시보드는 최신 저수율, 최근 7일 변화, 저수위, 관측일, 그래프 축·점 도구 설명·경계선을 표시한다.
5. 동일 시·군·구 저수지 비교와 작물·생육 단계·면적 기반 절수 시나리오를 이용해 현장 협의의 출발점을 만든다.

## 위험 판단 기준과 설명 가능성

판단은 공식 가뭄 경보를 대체하지 않는 의사결정 보조 정보다. 저수율 35% 이하 또는 최근 7일 15%p 이상 하락이면 주의, 저수율 50% 이하 또는 최근 7일 7%p 이상 하락이면 관심, 그 외는 안정으로 표시한다. 화면에는 어떤 기준이 적용됐는지, 관측 건수·예상 기간·누락 건수·최신 관측일을 함께 제시한다. 따라서 사용자는 결과뿐 아니라 결과가 나온 이유와 데이터의 한계를 확인할 수 있다.

## 핵심 기능 명세

### 1. 지역 중심 탐색

- 17개 시·도 예시 선택지를 제공하고, 선택한 시·군·구에 맞는 KRC 저수지를 실시간으로 조회한다.
- 강원특별자치도·제주특별자치도 등도 선택 가능하다. KRC 원자료에 해당 지역 또는 세부 행정구역 후보가 없으면 빈 결과를 오류가 아닌 안내 메시지로 처리한다.
- 이용자는 시설 코드를 알거나 입력할 필요가 없다.

### 2. 인터랙티브 저수율 추세

- 7·30·90일 단위 전환, Y축 저수율 수치, X축 관측일, 50% 관심선과 35% 주의선을 제공한다.
- 각 관측점에 마우스를 올리면 날짜·저수율·수위를 확인할 수 있다.
- 최신 관측일을 분리해 표시하므로 데이터 갱신 시점과 실시간성을 혼동하지 않는다.

### 3. 동일 지역 비교와 절수 시나리오

- 동일 시·군·구의 저수지를 최근 저수율과 7일 변화 기준으로 비교해 우선 확인 대상을 정렬한다.
- 논·밭작물·과수, 일반 생육·용수 수요 피크·수확 후, 면적을 입력하면 기본·10%·20% 절수 시나리오의 일일 예상 용수 수요를 비교한다.
- 시나리오는 현장 협의용 추정치이며 토양·기상·시설 상태를 추가 확인해야 함을 명시한다.

### 4. 데이터·AI 거버넌스

- 브라우저에는 인증키를 두지 않고 서버 환경변수에서만 KRC API를 호출한다.
- API 오류·빈 응답은 실패 이유를 사용자에게 안내하고, 그럴듯한 예시 수치로 대체하지 않는다.
- 서버는 매일 KRC 관측치를 수집하고 기준모델과 후보모델을 같은 검증 방식으로 비교한다.
- 탑정저수지 365일 데이터의 7일 예측 검증에서 기준모델(전일값 유지)은 MAE 9.817%p, MAPE 18.913%였고 Gradient Boosting 후보는 MAE 18.633%p, MAPE 41.386%였다. 후보가 기준보다 나빠 배포 모델로 채택하지 않았다.
- 다음 단계는 강수량·가뭄 단계·용수 수요 특성을 결합한 뒤 동일한 기준으로 재검증하는 것이다. 이 결과와 배제 사유를 대시보드에도 표시한다.

| 창의성 20 | 수위 조회를 지역 기반 위험 근거와 공동 절수 협의 흐름으로 전환 |

| AI 활용성 20 | 모델 성능을 수치로 검증하고 미달 후보는 배포하지 않는 설명 가능한 AI 운영 |
| 완성도 10 | 랜딩과 실제 도구를 분리하고 오류·결측·관측일·면책 범위를 명확히 표시 |

## 발표 시연 순서

1. 랜딩에서 서비스 목적과 세 가지 핵심 가치를 30초 안에 소개한다.
2. 실제 대시보드에서 지역을 고르고 저수지를 선택한다.
3. 추세 그래프의 축, 경계선, 점 도구 설명으로 원자료와 판단 근거를 보여 준다.
4. 동일 지역 비교와 작물별 절수 시나리오를 통해 수치 조회가 행동 협의로 이어짐을 설명한다.
5. 모델 검증 영역에서 성능 미달 후보를 배포하지 않은 근거를 제시한다.

## 운영·보안 원칙

- 인증키는 `.env` 또는 배포 플랫폼의 비밀 환경변수에만 보관하고 Git·문서·화면·URL에 포함하지 않는다.
- 실제 배포 전 HTTPS, 요청 제한, 접근 로그 마스킹, API 오류 모니터링을 적용한다.
- 본 서비스의 위험 표시는 법정 가뭄 경보, 급수 지시, 농업용수 배분 결정을 대체하지 않는다.
