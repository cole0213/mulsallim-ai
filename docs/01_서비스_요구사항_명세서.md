# 물살림 AI 서비스 요구사항 명세서

## 1. 서비스 정의

### 1.1 목적

농업용 저수지의 수위·저수율 정보를 농민과 관리자가 즉시 행동으로 옮길 수 있는 `안정 관개 가능일`, `위험 근거`, `우선 점검 순위`로 변환한다.

### 1.2 사용자

| 사용자 | 핵심 질문 | 제공 가치 |
|---|---|---|
| 농민 | 지금 관개해도 되는가? | 관개·절수·재확인 시점 안내 |
| 공사·지자체 담당자 | 어디부터 점검해야 하는가? | 위험 저수지 우선순위와 근거 |
| 귀농·일반 국민 | 이 지역의 용수 리스크는 어떤가? | 지역 단위 용수 안정성 이해 |

### 1.3 비목표

- 자동 개폐·자동 관개 제어
- 재난 경보의 공식 발령
- 수질 데이터 미연동 상태의 수질 판정
- 개인 농지·개인 경영정보의 무단 수집

## 2. 핵심 기능 요구사항

### FR-01 권역 현황 요약

- 평균 안정 관개 가능일, 주의 이상 저수지 수, 평균 저수율, 향후 3일 강수량을 표시한다.
- 모든 요약 수치에는 데이터 기준시각을 함께 표시한다.
- API 실패 시 마지막 성공 데이터와 갱신 실패 상태를 표시한다.

### FR-02 저수지 우선순위 목록

- 저수지명, 시·군, 상태, 저수율, 평년 대비, 안전일, 권장 조치를 표시한다.
- 이름·시군 검색, 상태 필터, 위험도/안전일/저수율 정렬을 지원한다.
- 저수지 선택 시 상세 분석 화면을 갱신한다.

### FR-03 저수지 상세 분석

- 최근 7일 저수율 추세를 그래프로 표시한다.
- 현재 저수율, 평년 대비 편차, 단기 강수량, 수위 하락 추세를 위험 근거로 표시한다.
- 농민용 행동지침과 관리자용 점검지침을 분리해 제공한다.
- 원인을 단정하지 않고 `점검 필요`, `확인 권고`처럼 보수적으로 표현한다.

### FR-04 관개 처방 시뮬레이터

- 사용자는 저수지, 작물, 생육 단계, 재배 면적을 입력한다.
- 서비스는 추정 일일 용수 수요와 해당 저수지의 안전일을 함께 보여준다.
- 결과에는 시뮬레이션의 한계와 실제 처방에 필요한 추가 데이터를 표시한다.

### FR-05 관리자 점검표 내보내기

- 주의 단계 저수지와 권장 조치를 JSON 또는 CSV로 내려받는다.
- 내려받기 파일에는 생성시각과 데이터 상태(시연/실데이터)를 포함한다.

## 3. 데이터 명세

### 3.1 입력 데이터

| 데이터 | 제공 기관 | 필수 항목 | 사용 목적 |
|---|---|---|---|
| 농촌용수 저수지 수위정보 조회 | 한국농어촌공사 | 저수지 코드, 수위, 저수율, 관측일시 | 현재 상태·수위 변화 계산 |
| 가뭄지도 정보 | 한국농어촌공사 | 평년저수율, 가뭄 단계, 유효저수량, 수혜면적 | 지역 위험도 보정 |
| 단기예보 | 기상청 | 예보시각, 강수확률, 강수량 | 단기 회복 가능성 반영 |
| 작물별 용수 정보 | 농촌진흥청 등 | 작물, 생육 단계, 필요 수분량 | 처방 시뮬레이션 보조 |

### 3.2 내부 표준 모델

```json
{
  "id": "reservoir-code",
  "name": "저수지명",
  "district": "시군",
  "asOf": "2026-07-31T09:00:00+09:00",
  "storageRate": 42.1,
  "normalDeviation": -8.4,
  "droughtStage": "관심",
  "forecastRainMm3d": 12.0,
  "safetyDays": 17,
  "riskLevel": "watch",
  "riskFactors": []
}
```

### 3.3 데이터 품질 규칙

- 관측시각이 48시간을 넘으면 `갱신 지연`으로 표시한다.
- 저수율이 0~100 범위를 벗어나면 분석에서 제외하고 오류를 기록한다.
- 동일 저수지·동일 관측시각은 가장 최근 수집값 하나만 유지한다.
- 결측값은 0으로 대체하지 않고 `데이터 부족`으로 표시한다.

## 4. 위험도·안전일 산출 명세

### 4.1 위험도 요소

| 요소 | 의미 | 방향 |
|---|---|---|
| 저수율 | 현재 저장 여력 | 낮을수록 위험 증가 |
| 평년 대비 편차 | 계절적 정상 범위 대비 부족 정도 | 낮을수록 위험 증가 |
| 최근 하락 추세 | 최근 7일 수위·저수율 변화 | 빠르게 하락할수록 위험 증가 |
| 단기 강수량 | 향후 회복 가능성 | 적을수록 위험 증가 |
| 가뭄 단계 | KRC 지역 위험 정보 | 단계가 높을수록 위험 증가 |

### 4.2 MVP 산출 방식

MVP에서는 규칙 기반 복합 위험점수로 시작한다. 실제 이력 데이터가 축적되면 시계열 예측 모델과 이상탐지 모델을 추가한다.

```text
위험점수 = 저수율 위험 + 평년편차 위험 + 하락추세 위험 + 강수부족 위험 + 가뭄단계 위험

0~29점  : 안정
30~59점 : 관심
60점 이상: 주의
```

`안정 관개 가능일`은 위험점수와 저장 여력의 상대지표다. 물리적 공급량이나 공식 가뭄 경보를 대체하지 않는다.

## 5. AI 적용 명세

| 단계 | MVP | 실서비스 고도화 |
|---|---|---|
| 위험 판정 | 설명 가능한 규칙 기반 복합 점수 | 시계열 예측 모델 |
| 이상 감지 | 인근·과거 대비 급감 조건 탐지 | Isolation Forest 등 이상탐지 |
| 설명 | 위험 요인 템플릿 문장 | LLM 기반 쉬운 말 요약, 근거 필수 표시 |
| 품질 검증 | 시연 데이터 시나리오 점검 | 과거 실제 데이터 백테스트 |

LLM은 수치 판정자가 아니라, 검증된 분석 결과를 이해하기 쉬운 문장으로 설명하는 역할만 맡는다.

## 6. 보안·운영 명세

- 공공 API 인증키는 백엔드 환경변수에만 저장한다.
- 브라우저는 자체 `/api/reservoirs` API만 호출한다.
- 개인 농지·농민정보는 동의 없이 저장하지 않는다.
- API 장애 시 마지막 데이터 기준시각과 장애 상태를 공개한다.
- 모든 결과에 `의사결정 보조용` 고지를 표시한다.

## 7. 수용 기준

- [ ] 저수지 검색·필터·정렬이 정상 작동한다.
- [ ] 저수지 선택에 따라 그래프·위험 근거·처방이 함께 변경된다.
- [ ] 작물·면적 입력에 따라 관개 시뮬레이션 값이 변경된다.
- [ ] 점검표 파일을 내려받을 수 있다.
- [ ] 모바일 화면에서 주요 기능을 사용할 수 있다.
- [ ] 시연 데이터와 실데이터 상태가 혼동되지 않게 표시된다.
