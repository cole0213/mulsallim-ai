# 지역 선택 UI 반영사항

`05_최종_통합_서비스_명세_및_한글원고.md`의 공개용 화면 설명은 아래 내용으로 보완한다.

## 사용자 흐름

1. 사용자는 **시·도 → 시·군·구 → 읍·면·동(선택)** 순서로 지역을 선택한다.
2. 서버는 선택한 시·도를 KRC `reservoircode` API의 `county` 조건으로 조회한다.
3. 반환된 저수지의 위치 정보에서 선택한 시·군·구를 필터링하고, 사용자는 저수지명·위치만 보고 대상을 선택한다.
4. 선택된 시설의 `fac_code`는 브라우저에 표시하지 않고 내부 상태에서만 사용한다.
5. 서버가 해당 코드로 `reservoirlevel` API를 호출해 실제 관측 수위·저수율을 제공한다.

## 데이터 한계의 정직한 고지

KRC 코드조회 원자료는 일반적으로 시·군 단위 위치를 반환한다. 읍·면·동까지 반환되지 않는 경우 서비스는 일치하는 결과가 없다고 표시하며, 임의의 시설코드를 추정하거나 다른 지역 데이터를 대신 보여주지 않는다.

## 화면 경로

- 공개 랜딩·지역 조회: `regional-service.html`
- 담당자 운영 관제: `control-center.html`
- 기존 직접 조회 시연: `operations-live.html`

## 심사 관점 반영

시설코드 같은 공공데이터의 기술 필드는 숨기고 지역 기반 사용자 경험을 제공한다. 동시에 선택한 저수지명, 위치, 관측일, KRC 원자료 여부를 표시해 데이터 출처·판단 근거의 투명성을 유지한다.
