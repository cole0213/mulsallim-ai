# 물살림 AI 대상권 실증 단계 — 최신 기준 v10

> 최종 갱신: 2026-07-24  
> 제출·시연에서 이전 v2~v9 경로 또는 단일 저수지 AI 검증 주장 대신 이 기준을 사용한다.

## 현재 상태

물살림 AI는 KRC 공공데이터를 지역 선택·변화 근거·현장 협의까지 연결한 서비스이며, v10에서 다지역 시간 분리 검증과 익명 파일럿 지표 수집을 추가했다.

## 새 AI 증거

- 9개 권역 18개 저수지, 6,588개 일별 관측을 수집했다.
- 저수지별 과거 70%만 학습하고 미래 30%(1,908개 예시)를 홀드아웃 평가했다.
- 7일 저수율 예측: 현재값 유지 MAE 3.525%p보다 기울기 투영 4.198%p가 나빠 **예측값 미배포**.
- 7일 내 5%p 하락 확인 신호: 저수율 50% 이하 기준 F1 0.040 대비 세 특징 후보 F1 0.062. 개선됐지만 재현율 0.037로 낮아 **자동 알림 미배포**.
- 현재 AI의 배포 범위는 ‘현장 확인 우선순위의 설명 가능한 보조 근거’다.

## 실증 원칙

- 파일럿 KPI에 실제 응답이 없으면 0건·미측정으로 보여주며 성공으로 해석하지 않는다.
- 파일럿 설문에는 이름·연락처·정확한 농지 주소를 넣지 않는다.
- 설문 응답은 90일, 협의 카드는 30일 뒤 자동 정리한다.
- 사용성·업무 효과·AI 성능을 하나의 점수로 합치지 않는다.
- 실제 참여자 수·역할·기간·불편 의견·중도 이탈을 함께 공개한다.

## 제출 원고에서 강조할 문장

> 물살림 AI의 차별점은 예측값을 과장하는 데 있지 않습니다. 18개 저수지의 미래 홀드아웃 검증에서 기준선보다 나쁜 예측은 배포하지 않았고, 개선 폭이 부족한 위험 신호도 자동 경보로 만들지 않았습니다. 대신 공공데이터를 누구나 이해할 수 있는 변화 근거와 현장 협의로 연결하고, 파일럿에서 실제 확인 시간을 줄이는지 측정합니다.

## 외부 실증 전 남은 작업

- [ ] 농업인·수리계 5명 이상, 현장 담당자 3명 이상 사용성 세션
- [ ] 4주 파일럿의 과업 성공률·첫 결과 도달시간·카드 완료율·익명 점수 수집
- [ ] 기상청·가뭄·용수수요 등 정식 데이터 결합 권한 확보
- [ ] 지역 통째 홀드아웃과 계절별 오경보 평가
