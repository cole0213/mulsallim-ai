# 물살림 AI — 절수 전환 의사결정 서비스 명세서

## 핵심 요약

물살림 AI는 저수율을 조회하거나 공식 가뭄 전망을 대체하는 서비스가 아니다. KRC 원자료를 바탕으로 **누가, 언제, 어떤 근거로 절수 협의를 시작해야 하는지**를 설명하고, 절수 선택에 따른 전환 시점의 지연 효과를 지역 구성원이 함께 검토·공유하게 하는 실행형 의사결정 서비스다.

## 최종 시연 경로

- 랜딩: `http://localhost:4182/mulsallim-home.html`
- 실제 의사결정 대시보드: `http://localhost:4182/mulsallim-action.html`
- 이전 조회형 화면은 개발 이력이며, 제출·발표에는 위 두 경로만 사용한다.

## 1. 문제 재정의

ADMS 농업가뭄관리시스템은 이미 저수율 현황, 지도, 가뭄 예경보, 저수율 전망을 제공한다. 따라서 단순 수위 조회·예측은 기존 공공서비스와 중복될 수 있다. 물살림 AI의 문제는 “저수율 정보를 어디서 볼 것인가”가 아니라 “원자료와 공식 정보가 있어도 현장에서 절수 협의가 늦어지는 이유는 무엇인가”이다.

현장에서는 다음 네 가지 질문에 한 번에 답해야 한다.

1. 이번 주 절수 협의를 시작해야 하는가?
2. 현재 하락이 계속되면 관심·주의 기준에 언제 도달하는가?
3. 10%·20% 절수 가정은 그 시점을 얼마나 늦출 수 있는가?
4. 같은 시·군에서 누구와 먼저 협의해야 하는가?

## 2. 기존 서비스와의 차별성

| 구분 | ADMS 등 공식 정보 | 물살림 AI |
| --- | --- | --- |
| 핵심 역할 | 저수율·가뭄·전망·공식 예경보 제공 | 협의 시작 시점과 절수 선택을 설명·공유 |
| 사용자 질문 | 현재 가뭄 상태는 무엇인가 | 이번 주 누구와 무엇을 결정해야 하는가 |
| 출력 | 지도, 현황, 전망, 예경보 | 전환 신호, 도달 시점, 절수 지연 효과, 지역 우선순위, 브리핑 |
| 판단 책임 | 공식 운영 기준 | 공식 정보와 현장 확인을 연결하는 의사결정 보조 |
| 데이터 태도 | 공식 정보 제공 | 원자료·가정·누락·한계를 화면에서 공개 |

공식 ADMS의 예경보와 저수율 전망은 물살림 AI가 참조해야 할 권위 있는 정보다. 물살림 AI는 이를 대체한다고 주장하지 않고, 현장 협의와 기록에 필요한 실행 레이어로 자리 잡는다.

## 3. 전환 판단 엔진

### 입력

- KRC `reservoirlevel`: 관측일, 수위, 저수율
- KRC `reservoircode`: 지역 기반 저수지 탐색
- 사용자가 고른 작물, 생육 단계, 농지 면적

### 산출

- AI 전환 신호(0~100): 협의 필요성을 비교하기 위한 탐지 점수
- 최신 저수율과 최근 7일 변화
- 관심선 50%, 주의선 35% 도달 추정일
- 절수 0%·10%·20% 가정별 주의선 도달 시점
- 동일 시·군 내 우선 협의 저수지 순위
- 담당자·농업인 공유용 텍스트 브리핑

### 계산의 설명 가능성

전환 신호는 다음 요소를 가중해 0~100으로 산출한다.

- 저수율 위험: 낮은 저수율일수록 증가
- 최근 7일 하락 위험: 급격한 하락일수록 증가
- 변화 이상도: 최근 7일 강건 추세를 과거 일별 변화의 중앙값·MAD(중앙절대편차)와 비교
- 데이터 신뢰도: 관측 누락일이 많을수록 감점

강건 추세는 최근 관측점의 모든 쌍별 기울기 중앙값(Theil–Sen 방식)을 사용한다. 단일 이상치에 덜 흔들리도록 설계했으며, 사용자는 각 구성요소와 원자료 개수를 화면에서 확인한다.

## 4. 절수 시나리오의 정직한 범위

관심·주의선 도달 시점은 최근 하락 추세가 유지된다는 탐색 가정 아래 계산한다. 10%·20% 절수 시나리오는 절수율만큼 순감소 속도가 줄어든다고 가정한다. 따라서 이는 급수 지시나 확정 예측이 아니라, 농업인·담당자가 “지금 절수 협의를 시작하면 어떤 차이가 있는가”를 토론하기 위한 비교 도구다.

실제 배분·급수 결정에는 강수·유입량·수리시설 상태·작물 수요·ADMS 공식 예경보·현장 점검을 반드시 함께 반영한다. 이 한계를 인터페이스와 공유 보고서에 반복 표시한다.

## 5. AI 활용의 책임 있는 전략

### 현재 배포 기능

- 데이터 적응형 전환 신호 탐지: 최근 하락 추세와 과거 변동성의 관계를 분석
- 설명 가능한 우선순위화: 점수 구성요소와 근거 문장을 공개
- 모델 거버넌스: 후보 예측 모델은 기준모델과의 검증을 통과해야만 배포

### 검증 결과

탑정저수지 365일 관측치의 7일 예측에서 전일값 유지 기준모델은 MAE 9.817%p, MAPE 18.913%였고 Gradient Boosting 후보는 MAE 18.633%p, MAPE 41.386%였다. 후보가 기준보다 낮아 서비스 예측으로 배포하지 않았다.

### 다음 고도화

강수량, ADMS 가뭄 단계, 유효저수량, 수혜면적, 작물별 수요를 결합한 다변량 예측 후보를 같은 시계열 검증으로 평가한다. 기준모델을 이기고, 지역·계절별 오차와 불확실성까지 공개할 수 있을 때만 예측 기능을 켠다.

## 6. 도입·사업성 설계

### 초기 파일럿

KRC 지사 또는 지자체 1곳, KRC 관리 저수지 5~10곳, 농업인 대표 그룹을 대상으로 8주 파일럿을 진행한다. 매주 전환 신호 상위 저수지의 현장 확인 여부와 협의 결과를 기록한다.

### 검증 KPI

| 목표 | 측정 방식 |
| --- | --- |
| 협의 리드타임 단축 | 위험 신호 발생일부터 첫 협의까지 걸린 시간 비교 |
| 점검 우선순위 정확성 | 상위 순위 저수지의 담당자 확인 일치율 |
| 의사결정 이해도 | “왜 이 저수지를 먼저 봐야 하는지 알 수 있다” 설문 점수 |
| 절수 협의 전환율 | 시나리오 열람 후 실제 협의·점검 기록 비율 |
| 데이터 신뢰성 | 원자료 관측일·누락 안내가 포함된 공유 브리핑 비율 |

### 확장 구조

1. KRC·지자체 담당자의 주간 협의 보조 도구
2. 농업인 단체와 관개 구역별 공동 절수 브리핑
3. 지역 맞춤 보고서·알림·현장 점검 이력 기능
4. 수혜면적·시설제원·기상·가뭄 단계가 갖춰진 권역의 다변량 예측 모듈

## 8. 3분 발표 흐름

1. “ADMS가 정보와 전망을 제공한다면, 협의는 누가 언제 시작할까?”라는 문제를 제시한다.
2. 지역·저수지를 선택하고 KRC 원자료와 데이터 신뢰 상태를 보여 준다.
3. AI 전환 신호와 근거 카드를 통해 이번 주 판단을 설명한다.
4. 관심·주의선 도달 추정과 10%·20% 절수의 지연 효과를 비교한다.
5. 동일 지역 우선순위와 TXT 브리핑으로 실제 협의 행동까지 연결한다.
6. 성능 미달 예측 후보를 배포하지 않은 모델 거버넌스로 책임 있는 AI를 마무리한다.
