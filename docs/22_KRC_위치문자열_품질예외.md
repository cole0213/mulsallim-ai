# KRC 위치문자열 품질 예외

## 핵심 요약

전남 위치 조회에서 KRC 원문이 `전남광주통합특별시 강진군`처럼 사용자 선택에 부적절한 형식으로 반환되는 예외를 확인했다. 원문을 변경하지 않고, 사용자 UI에서만 `전라남도 · 강진군`으로 정규화한다.

## 기록

### 정규화 원칙  <!-- (2026-07-24) -->

- API 원문은 서버 응답·감사 기록에서 보존한다.
- 사용자에게 보여 주는 시·도는 선택한 정식 명칭을 유지한다.
- 전라남도 선택 시 `전남광주통합특별시` 접두어를 제거하고 뒤의 시·군·구만 추출한다.
- 이 보정은 저수지 코드·관측일·저수율 값에는 개입하지 않으며, 위치 선택·표시 문자열에만 적용한다.
