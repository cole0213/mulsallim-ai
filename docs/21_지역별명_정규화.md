# KRC 지역별명 정규화

## 핵심 요약

사용자 화면의 행정구역 정식 명칭과 KRC 위치 조회에 필요한 표기가 다른 경우를 정규화했다. 현재 확인된 별칭은 전라남도→전남, 전북특별자치도→전북이다.

## 기록

### 실제 API 검증 기반 별칭 처리  <!-- (2026-07-24) -->

- `전라남도` 그대로 조회하면 KRC가 `NO_DATA`를 반환했지만, `전남`으로 조회하면 3일 기준 3,171건이 반환됐다.
- UI에는 전라남도 표기를 유지하고, API 요청 때만 전남으로 변환한다.
- KRC 응답의 `전남 ○○시`도 UI에서 `전라남도 ○○시`로 복원한다. 따라서 시·군 필터와 사용자가 보는 위치명이 일치한다.
- 전북특별자치도도 같은 원칙으로 전북 별칭을 사용한다.
