# 물살림 AI 최종 AI 전환 근거 추가

## 핵심 요약

최종 시연은 `mulsallim-final.html`에서 시작해 `mulsallim-action-final.html`로 이어진다. 기존의 설명 가능한 전환 신호에 실제 비지도 학습 기반 Isolation Forest 이상 탐지 근거를 추가했다.

## 기록

### Isolation Forest 근거  <!-- (2026-07-24) -->

- 입력 특성: 저수율, 최근 7일 기울기, 일별 절대 변화 평균.
- 학습 데이터: 탑정저수지 KRC 365일 관측에서 만든 358개 변화 패턴.
- 최신 관측(2026-07-24)의 이상 점수는 0.505, 과거 패턴 대비 76.0백분위였다.
- 이 모델은 가뭄 예측·경보 모델이 아니라 최근 변화가 해당 저수지의 과거와 얼마나 다른지 보여 주는 비지도 보조 근거다.
- 결과 파일: `transition-anomaly-evaluation.json`, 재현 스크립트: `server/transition_anomaly.py`, `server/run_transition_anomaly.py`.
- 관련: [[절수 전환 의사결정]], [[AI 모델 검증]]

## 사용 원칙

- Isolation Forest 결과 하나만으로 주의·관심을 부여하지 않는다.
- 저수율·7일 추세·관측 누락·현장 정보와 함께 전환 신호의 근거로 사용한다.
- ADMS 공식 예경보·급수 지시를 대체하지 않는다.
