# 위치 기반 저수지 조회 정정

## 핵심 요약

KRC 공식 명세를 다시 검토해, 위치 조건 `county`는 저수지 코드 조회가 아니라 수위 조회에 적용되는 조건임을 확인했다. 이에 따라 코드 조회를 지역 목록으로 오용하는 흐름을 중단하고, 최대 31일 위치 기반 수위 조회 결과에서 실제 시·군·구와 저수지를 도출하도록 변경했다.

## 기록

### 공식 명세 근거  <!-- (2026-07-24) -->

- 공공데이터포털 설명: 위치(`county`)로 저수율을 조회할 수 있으며, 위치 조회는 최대 31일 범위만 가능하다.
- 따라서 시설 코드 기반 상세 추세는 최대 365일, 위치 기반 목록 탐색은 최근 3일(최대 31일 이내)이라는 역할 분리를 적용했다.
- 지역 선택 후 흐름:
  1. `reservoir-by-county`로 최근 3일의 실제 위치 관측을 조회한다.
  2. 응답의 `county`에서 실제 시·군·구 목록을 만들고, 최신 관측값 기준으로 저수지를 중복 제거한다.
  3. 사용자가 저수지를 고르면 시설 코드를 내부적으로 사용해 최대 90일 상세 추세를 조회한다.

### 검증  <!-- (2026-07-24) -->

- 강원특별자치도: 237건, 12개 시·군·구 응답 확인.
- 제주특별자치도: 30건, 2개 시·군·구 응답 확인.
- 충청남도: 696건, 14개 시·군·구 응답 확인.
- 서울특별시: KRC 응답 `NO_DATA`. 서비스에서는 오류가 아니라 “조회 대상 없음”으로 안내한다.
