# 물살림 AI 원격 배포 승인 대기 사항

## 확인된 원격 서버 상태

- 서버: 사용자 지정 Ubuntu 서버
- 기존 서비스: Python 프로세스가 5000·5001 포트에서 실행 중이며 건드리지 않는다.
- Docker: 설치됨. `docker compose` 플러그인은 없음.
- 시스템 Node: v10이므로 앱은 Node 20 Docker 이미지로 분리 실행한다.
- 디스크 여유: 약 12GB. Node 20 이미지·앱 빌드에 충분하지만 불필요한 이미지는 쌓지 않는다.
- 방화벽: UFW 활성화 상태이며 4184 포트 허용 규칙 없음.

## 승인 후 수행할 변경

1. `/root/mulsallim_ai/releases/v12/`에 배포 번들 압축 해제
2. `node:20-alpine` 기반 이미지 `mulsallim-ai:v12` 빌드
3. 기존 컨테이너가 없으면 새 `mulsallim-ai` 컨테이너를 4184 포트로 실행
4. 서버의 기존 `.env`에서 재발급 KRC 키만 주입
5. `runtime/` 볼륨으로 협의 카드·파일럿 데이터 지속 보관
6. `ufw allow 4184/tcp`를 추가해 외부 접속 허용
7. 서버 내부·외부 HTTP, KRC 조회, 개인정보 차단, 컨테이너 재시작 지속성 검증

## 안전 경계

- 5000/5001 기존 서비스와 Nginx 설정은 변경하지 않는다.
- API 키·생성자 관리 키·개인정보를 배포 번들에 넣지 않는다.
- 도메인과 TLS 인증서가 없는 상태에서는 `http://서버IP:4184`만 제공된다. 전국 공개 서비스로 운영하려면 도메인·HTTPS 역프록시를 별도 승인 후 적용해야 한다.
- 배포는 `deploy-remote-v12-docker-run.sh`을 사용한다.
