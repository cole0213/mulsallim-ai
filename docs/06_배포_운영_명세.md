# 물살림 AI 배포·운영 명세

## 화면 역할

| 화면 | 대상 | 주소 | 핵심 기능 |
|---|---|---|---|
| 공개 랜딩·조회 | 농업인·심사위원 | `operations-live.html` | 저수지 검색, 실측 데이터, 추세, 시나리오 |
| 운영 관제 | 공사·지자체 담당자 | `control-center.html` | 최신 상태, 근거, 권고, 재조회 |

## 배포 아키텍처

브라우저 → 물살림 AI 웹 서버 → KRC OpenAPI 순서로 통신한다. KRC 인증키는 웹 서버의 `KRC_SERVICE_KEY` 환경변수에만 저장하며 프런트엔드 코드, URL, 저장소, 화면에 포함하지 않는다. 현재 `server-live-v5.js`가 정적 파일과 API 프록시를 함께 제공한다.

## 운영 규칙

- API 실패·빈 응답은 정상 데이터로 대체하지 않고 오류를 표시한다.
- 관측값은 KRC 원자료와 관측일을 함께 표시한다.
- 위험 단계·절수 시나리오는 ‘의사결정 보조’로 한정한다.
- 실제 외부 배포 전에는 키 재발급, HTTPS, 환경변수 주입, 접근 로그의 키 마스킹, 요청 제한을 적용한다.
- 모델 학습은 로컬 PC가 아니라 승인된 서버에서 수행한다.

## 수용 기준

- 저수지명·시도 검색 후 시설코드를 선택할 수 있다.
- 지정 기간의 수위·저수율을 그래프로 확인할 수 있다.
- 기간 변동, 판단 단계, 근거, 시나리오가 함께 변경된다.
- 브라우저 소스와 다운로드 파일에 API 키가 포함되지 않는다.
