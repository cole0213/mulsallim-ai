## 제출에서 쓰면 안 되는 문장

- “AI가 가뭄을 예측한다.”
- “예측 정확도가 검증됐다.”
- “파일럿에서 효과를 입증했다.” — 실제 결과가 생기기 전까지 금지
- “전국 모든 저수지에 적용됐다.” — 현재 다지역 평가 표본은 18개 저수지
- “공식 경보를 대체한다.”

## 제출 직전 확인

- [ ] 한글 파일은 v10만 첨부했는가
- [ ] 발표 자료의 수치가 `multiregion_evaluation.json`과 일치하는가
- [ ] 응답 수·파일럿 기간·참여 역할을 실제값으로 썼는가
- [ ] KRC API 키·협의 카드 생성자 키·개인정보가 포함되지 않았는가
- [ ] 기본 URL에서 제주·경북 등 실제 관측 지역을 시연해 봤는가
- [ ] 모델카드의 ‘미배포’ 결정을 숨기지 않았는가
