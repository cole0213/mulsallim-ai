# 물살림 AI 최종 제출 명세서 및 원고

> **제출 기준 문서**. 이전 `00~07` 문서는 작업 이력이며, 신청서·발표자료·웹 링크에는 본 문서만 반영한다.

## 1. 서비스 기본정보

- 분야: 서비스개발 / 안전강화
- 서비스명: **물살림 AI - 지역 농업용수 위험 판단 및 공동 절수 시나리오 서비스**
- 랜딩 페이지: `http://localhost:4182/landing.html`
- 실제 대시보드: `http://localhost:4182/regional-service-v2.html`
- 서비스 형태: 공개 랜딩 페이지 + 지역 선택형 웹 대시보드

## 2. 서비스 개요

물살림 AI는 한국농어촌공사 농업용저수지 수위정보를 지역 농업인이 이해하고 활용할 수 있는 변화·위험 근거·절수 선택지로 바꾸는 웹 서비스이다. 사용자는 시·도, 시·군·구, 읍·면·동을 선택하고 저수지명만 선택한다. 시설코드는 내부에서만 사용하며, 서비스는 실제 관측 수위와 저수율을 조회한다.

단순 조회를 넘어 최신 저수율, 선택 기간 변화, 위험 기준, 관측일, 지역 내 저수지 비교, 농지 조건별 절수 시나리오를 함께 제공한다. 모든 판단은 공식 가뭄 경보나 급수 지시를 대체하지 않는 의사결정 보조 정보임을 명시한다.

## 3. 구현 기능

1. **KRC 원자료 연동**: `reservoircode`로 지역별 시설을 찾고, `reservoirlevel`로 일별 `check_date`, `water_level`, `rate`를 조회한다. 인증키는 서버 환경변수 또는 권한 600의 서버 설정 파일에만 저장한다.
2. **지역 기반 사용자 경험**: 시·도→시·군·구→읍·면·동 순으로 선택하며 사용자는 시설코드를 보지 않는다. 읍·면·동 데이터가 KRC 원자료에 없으면 결과 없음을 정확히 안내한다.
3. **설명 가능한 위험 판단**: 저수율 35% 이하 또는 기간 15%p 이상 급락은 주의, 저수율 50% 이하 또는 7%p 이상 하락은 관심으로 분류한다. 화면에는 저수율·변화폭·관측일을 근거로 표시한다.
4. **시각화·신뢰 표시**: 저수율 그래프는 날짜·저수율 축, 관측 점, 툴팁, 관심 50%·주의 35% 기준선을 제공한다. API 오류, 빈 데이터, 관측기간과 최신 관측일을 숨기지 않는다.
5. **지역 비교·절수 협의**: 같은 시·군 저수지를 저수율·변화폭으로 비교하고, 논/밭작물/과수와 면적 입력에 따라 기본·10%·20% 절수 시 일일 용수 수요를 비교한다.

## 4. AI 활용 및 검증

MVP의 위험 판단은 검토 가능한 규칙 기반으로 제공한다. 서버에서는 탑정저수지 최근 365일 관측값으로 7일 저수율 예측을 검증했다. 전일값 유지 기준모델은 MAE 9.817%p, MAPE 18.913%였고, 현재 특성만 쓴 Gradient Boosting은 MAE 18.633%p, MAPE 41.386%로 기준모델보다 낮았다.

따라서 성능이 낮은 후보모델을 서비스 예측으로 사용하지 않는다. 이후 기상 강수량, KRC 가뭄 단계, 작물·용수 수요 특성을 추가하고 동일한 시계열 검증으로 기준모델을 이길 때만 배포한다. 이는 성능을 과장하지 않는 책임 있는 AI 원칙이다.

## 5. 차별성·사업성

기존 저수율 조회·예측 정보와 달리 물살림 AI는 사용자가 ‘얼마나 남았는가’만 보는 대신, 지역의 저수지 변화를 비교하고 공동 절수 전환을 논의하도록 돕는다. 초기에는 KRC 또는 지자체의 5~10개 저수지 시범 운영으로 점검 우선순위·절수 협의 시간·사용자 만족도를 측정한다. 이후 지역 맞춤 운영 화면과 보고서로 확장한다.

## 6. 데이터·보안·운영

- KRC 인증키는 브라우저, URL, 저장소, 다운로드 파일에 포함하지 않는다.
- 서버는 매일 KRC 관측값 수집과 후보모델 재평가를 자동 실행한다.
- 데이터 부족, API 오류, 성능 미달 모델은 성공으로 표시하지 않는다.
- 실제 외부 배포 전에는 HTTPS, 키 재발급, 요청 제한, 접근 로그 마스킹을 적용한다.

## 7. 발표 시연 순서

1. 랜딩에서 문제와 지역 기반 서비스 가치를 설명한다.
2. 실제 대시보드에서 지역 선택 후 저수지를 선택한다.
3. KRC 실측 그래프, 저수율·기간 변화·위험 근거를 확인한다.
4. 같은 시·군 비교와 농지 절수 시나리오를 보여준다.
5. 모델 검증 결과와 성능 미달 후보모델을 배제한 이유를 설명한다.
