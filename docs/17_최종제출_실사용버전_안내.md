## 이 문서가 최신 기준인 이유

이 문서는 이전 랜딩·관제·시연 문서를 대체하는 최신 제출 기준이다. 서비스의 중심을 “AI가 무엇을 계산하는가”에서 “농업인과 현장 담당자가 반복해서 무엇을 확인하고 행동하는가”로 옮겼다.

## 의도적으로 제거·후순위화한 것

- 일반 사용자 첫 화면의 작물·면적 기반 시나리오: 실제 농가 조건을 모르는 가정이므로 현장 판단을 흐릴 수 있다.
- 동일 지역 저수지 우선순위 비교: 현장 담당자의 별도 운영 화면으로 분리할 성격이며, 농업인의 첫 과업이 아니다.
- “AI 예측 정확도” 중심 표현: 실제 검증에서 후보 모델이 기준선을 이기지 못했으므로 사용하지 않는다.

## 남은 고도화 과제와 제출 시 표현 원칙

1. **읍·면 단위 선택**: 현재 KRC 코드 조회 응답의 위치 단위가 시·군 중심이므로, 검증되지 않은 읍·면 매핑을 만들어 보여 주지 않는다. KRC 시설 좌표/상세 위치 또는 지자체 행정구역 데이터와 공식 결합이 가능해진 뒤 지도·읍면 선택을 추가한다.
2. **푸시 알림**: 현재는 관심 저수지와 캘린더 재확인 파일로 반복 확인을 돕는다. 실제 알림은 로그인·동의·수신 거부·오탐 대응 정책을 갖춘 뒤 도입한다.
3. **현장 메모 공유**: 현재 메모는 브라우저 기기에만 저장한다. 서버 공유 전에는 개인정보·보관기간·권한 정책 및 KRC/지자체 협의가 필요하다.
4. **현장 검증**: 파일럿 성과를 이미 보유했다고 주장하지 않는다. 농업인·담당자 5~10명에게 지역 선택 성공률, 판단 이해도, 브리핑 공유성, 재방문 의향을 검증한다.

## 시연 체크 순서

1. 랜딩에서 충청남도 → 논산시 선택.
2. 탑정 저수지 선택.
3. 최신 관측일·저수율·7일 변화와 그래프 툴팁 확인.
4. 판단 근거와 데이터 신뢰도를 확인.
5. “이번 주 현장 행동” 체크리스트와 ADMS 공식 정보 연결 확인.
6. 현장 메모 저장, 브리핑 복사, 재확인 일정 저장.
