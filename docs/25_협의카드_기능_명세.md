# 현장 확인 카드 기능 명세

## 핵심 요약

물살림 AI는 단순 조회·로컬 메모에서 한 단계 나아가, 저수지 관측 근거와 현장 확인 항목을 익명 공유 카드로 만든다. 이를 통해 농업인·현장 담당자가 같은 수치와 같은 확인 항목을 보며 협의를 시작할 수 있다.

## 사용자 흐름

1. 사용자가 지역·저수지를 고르고 관측 근거와 이번 주 행동을 확인한다.
2. 개인정보를 제외한 현장 메모를 입력해 30일짜리 확인 카드를 만든다.
3. 공개 링크는 읽기 전용으로 공유한다.
4. 생성자만 가진 관리 키로 상태를 `확인 요청 → 현장 확인 중 → 확인 완료`로 바꾼다.

## 안전 원칙

- 카드에는 이름·연락처·정확한 농지 주소를 쓰지 않도록 UI에서 안내한다.
- 공개 조회 응답에는 관리 키를 포함하지 않는다.
- 상태 변경은 관리 키가 없으면 HTTP 403으로 차단한다.
- 카드 데이터는 로컬 서버 파일에 30일만 보관한다.
- 실제 운영 확장 시에는 기관 로그인, 권한, 감사 로그, 개인정보처리방침을 추가해야 한다.

## 검증

- 생성: HTTP 201
- 공개 조회: 관리 키 비노출
- 생성자 상태 변경: 정상
- 무권한 상태 변경: HTTP 403

## 심사 기준 연결

- 활용성: 관측값이 현장 점검·협의로 이어짐
- 창의성: 공식 정보 화면과 다른 ‘협의 시작 카드’
- 사업성: 지자체·KRC 지사·농업인 대표가 공유할 수 있는 최소 운영 단위
- 완성도: 상태·보관기간·권한 경계가 구현됨
