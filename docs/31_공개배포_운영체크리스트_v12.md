# 물살림 AI 공개 배포 운영 체크리스트 v12

## 배포 구조

- 실행 이미지: `node:20-alpine` 기반 Docker 컨테이너
- 앱 포트: `4184`
- 환경변수: 서버의 상위 `.env`에서 `KRC_SERVICE_KEY`만 주입. 이미지·저장소·브라우저에 키를 넣지 않는다.
- 지속 데이터: 서버의 `runtime/`을 컨테이너 `/data`에 연결한다.
  - 협의 카드: 30일
  - 익명 파일럿 피드백: 90일
- 기존 5000/5001 서비스와 컨테이너·포트를 공유하지 않는다.

## 배포 전

- [ ] 서버 `.env`에 재발급한 KRC 키가 설정됐는가
- [ ] 외부로 노출할 IP/도메인과 방화벽 포트 정책을 확인했는가
- [ ] `docker compose version`과 Docker daemon이 정상인가
- [ ] 이전 `mulsallim-ai` 컨테이너가 없다면 신규 실행, 있다면 상태·로그를 먼저 백업했는가
- [ ] HTTPS 도메인이 없다면 HTTP IP 주소는 평가·내부 시연용으로만 사용한다는 점을 고지했는가

## 배포 후 검증

- [ ] `/api/health`의 `krcConfigured: true`
- [ ] `smoke-test-public-v12.js` 통과
- [ ] 실제 외부 네트워크에서 지역 선택 → 저수지 상세 → 그래프 → 협의 카드 흐름 확인
- [ ] 전화번호·이메일을 넣은 협의 카드/피드백이 HTTP 400으로 거부되는지 확인
- [ ] 컨테이너 재시작 뒤 `runtime/`의 카드·피드백 데이터가 유지되는지 확인
- [ ] 컨테이너 health 상태가 healthy인지 확인

## 운영 중단 기준

- KRC 인증 오류·반복 API 실패
- 개인정보 입력 차단이 우회됨
- 예상치 못한 카드/피드백 데이터 손상
- 외부 노출 포트에 비정상 트래픽 또는 서버 자원 고갈

발생 시 컨테이너 로그를 보존하고, 서비스 중단·원인 수정·회귀 테스트 후 재개한다.
