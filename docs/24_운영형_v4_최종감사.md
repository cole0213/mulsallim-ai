# 물살림 AI 운영형 v4 최종 감사

## 핵심 요약

운영형 v4는 실제 KRC 위치 기반 수위 조회, 사용자 중심 랜딩·대시보드, 행동·공유·재확인, 접근성, 요청 보호를 하나의 로컬 실행 경로로 통합한다. 기능을 더 늘리는 대신 실제 데이터 근거·오류 회복·반복 사용 흐름을 검증했다.

## 요구사항별 증거

| 요구 | 구현·검증 증거 | 상태 |
| --- | --- | --- |
| 코드 없이 지역 선택 | 시·도→실제 KRC 시·군·구→저수지 흐름 | 구현·API 검증 |
| 전국 주요 지역 | 강원·제주·충남·경기·경남·경북·전북·충북 응답 확인, 전남 별칭 정규화 | API 검증 |
| 대상 없음 안내 | 서울 `NO_DATA`를 200 빈 결과로 변환, 랜딩 문구 제공 | 자동 검증 |
| 상세 판단 | 선택 코드로 상세 관측·그래프·7일 변화·근거·신뢰도 표시 | API·정적 검증 |
| 행동 기능 | 위험 단계 체크리스트, ADMS 연결, 기기 내 메모, 브리핑, 재확인 일정 | 구현 검증 |
| 신뢰 표시 | 관측일·공백·데이터 품질, AI 한계, 공식 판단 비대체 문구 | 구현·원고 반영 |
| 반복 사용 | 관심 저수지·최근 확인·ICS 재확인 일정 | 구현 검증 |
| 운영 보호 | API 키 환경변수, 5분 캐시, IP 요청 제한, timeout, no-store | 자동 검증 |

## 자동 통합 검증 결과  <!-- (2026-07-24) -->

`node smoke-test-production-v4.js`

- 제주 위치 조회: 30건
- 서울: `noData: true`
- 캐시 엔트리: 첫 요청 뒤 1건, 같은 요청 뒤에도 1건 유지
- 최신 랜딩·대시보드·스크립트: HTTP 200

## 아직 자동으로 증명되지 않은 것

- 실제 브라우저에서의 시각적 레이아웃·클릭 완주: 현재 자동 브라우저 실행 환경의 sandbox 오류로 수동 시연이 필요하다.
- 농업인·현장 담당자의 반복 사용성: 파일럿 테스트가 필요하며, 검증 완료라고 주장하지 않는다.
- 읍·면 정밀 선택: KRC 위치 응답의 시·군 단위 한계 때문에 공식 시설 좌표·행정구역 데이터 결합 후에 추가한다.
