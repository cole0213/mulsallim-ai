# 물살림 AI 최종 통합검증 기준

## 핵심 요약

최종 시연 전에는 `node smoke-test-v3.js`를 실행해 KRC 인증·위치 목록·상세 추세·조회 대상 없음 처리를 함께 확인한다. 이 자동 검증은 실제 브라우저 시연을 대체하지 않으며, 이후 수동 시연 체크도 수행한다.

## 자동 검증 범위

- `GET /api/health`: KRC 키 구성 상태
- 제주특별자치도 위치 기반 최근 관측: 관측 건수와 저수지 중복 제거 가능 여부
- 제주 표본 저수지 상세 수위: 코드 기반 상세 추세 조회
- 서울특별시: `NO_DATA` 오류 계약 확인

## 수동 시연 체크

1. `http://localhost:4183/mulsallim-public-county-v3.html`을 연다.
2. 제주특별자치도 → 제주시 → 저수지 하나를 선택한다.
3. 그래프 수치, 판단 근거, 이번 주 행동, 데이터 신뢰도 문구를 확인한다.
4. 현장 메모 저장·브리핑 복사·재확인 일정 저장을 확인한다.
5. Tab/Enter와 그래프 좌우 화살표를 확인한다.
6. 전라남도 → 강진군을 선택해 정규화된 위치 표기를 확인한다.
7. 서울특별시 선택 시 “조회 대상 없음” 안내를 확인한다.

## 해석 원칙

- 자동 검증 통과는 API·서버 연결의 증거다.
- 실제 농업인 반복 사용성은 파일럿으로만 검증 가능하며, 완료된 성과처럼 주장하지 않는다.
