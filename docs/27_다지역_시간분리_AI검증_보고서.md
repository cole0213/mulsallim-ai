# 물살림 AI 다지역 시간 분리 검증 보고서

> 생성일: 2026-07-24  
> 재현 코드: `server/collect_multiregion.js`, `server/evaluate_multiregion.py`  
> 원본 결과: `server/multiregion_evaluation.json`

## 목적

한 저수지의 예쁜 그래프가 아니라, 여러 권역에서 미래 데이터를 분리한 상태로 AI 후보를 평가한다. 이 결과는 자동 경보를 정당화하기 위한 자료가 아니라, **배포할 수 없는 기능을 명확히 보류하기 위한 증거**다.

## 데이터 범위

| 항목 | 값 |
|---|---:|
| 저수지 | 18개 |
| 권역 | 강원·경기·경남·경북·전남·전북·충남·충북·제주, 9개 |
| KRC 일별 관측 | 6,588건 |
| 각 저수지 기간 | 최근 366일 |
| 학습 / 홀드아웃 | 저수지별 시간순 70% / 30% |
| 학습 / 홀드아웃 예시 | 4,428 / 1,908 |

## 검증 정의

- 관측일의 저수율에서 7일 뒤 저수율이 **5%p 이상 하락**하면 ‘현장 확인 필요 사건’으로 정의했다.
- 입력 특징은 현재 저수율, 최근 7일 기울기, 최근 7일 일별 변화의 표준편차다.
- 학습에 미래 행이 들어가지 않도록 각 저수지에서 먼저 과거 70%를 학습용으로 자르고, 이후 30%만 홀드아웃 평가에 사용했다.

## 결과

### 7일 저수율 예측

| 방법 | 홀드아웃 MAE | 결론 |
|---|---:|---|
| 현재값 유지 기준선 | 3.525%p | 기준 |
| 7일 기울기 투영 후보 | 4.198%p | 기준선보다 나빠 배포 제외 |

### 7일 내 5%p 이상 하락 ‘현장 확인 우선순위’

| 방법 | 정밀도 | 재현율 | F1 | 알림 비율 | 결론 |
|---|---:|---:|---:|---:|---|
| 저수율 50% 이하 단독 기준 | 0.057 | 0.031 | 0.040 | 9.2% | 기준 |
| 세 특징 정규화 로지스틱 후보 | 0.191 | 0.037 | 0.062 | 3.3% | 개선은 있으나 자동 경보 불가 |

후보는 기준선보다 정밀도와 F1은 높지만 재현율이 3.7%에 불과하다. 그러므로 이 결과를 “가뭄 예측 정확도”로 홍보하지 않으며, 현재 서비스에는 자동 알림·급수 지시·공식 판단 기능을 넣지 않는다.

## 서비스 반영 결정

1. 현재 배포: 최신 저수율·변화·관측 연속성의 **설명 가능한 현장 확인 우선순위**.
2. 배포 보류: 7일 저수율 예측값, 자동 위험 알림, 공식 가뭄 판단.
3. 공개: `mulsallim-ai-model-card-v3.html`에서 범위·성능·보류 근거를 사용자에게 그대로 알린다.
