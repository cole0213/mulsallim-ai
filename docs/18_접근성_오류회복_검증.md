# 물살림 AI 접근성·오류회복 검증

## 핵심 요약

실사용 대시보드에 키보드 초점 표시, 본문 건너뛰기, 결과 상태 알림, 키보드 그래프 탐색을 추가했다. API가 지역을 찾지 못하거나 필수값이 없을 때는 원인을 한국어로 안내하도록 기존 동작을 재확인했다.

## 기록

### 키보드와 화면 낭독 보강  <!-- (2026-07-24) -->

- `mulsallim-accessibility.js`는 키보드 초점이 눈에 보이도록 하고, 본문 건너뛰기 링크를 제공한다.
- 저수지 검색 결과 메시지는 `aria-live` 상태 영역으로 표시한다.
- 추세 그래프는 포커스를 받으면 최신 관측값을 읽고, 좌·우 화살표/Home/End로 날짜별 저수율·수위를 확인할 수 있다.
- 현장 메모 저장 결과는 상태 메시지로 연결한다.

### 실제 API 재확인  <!-- (2026-07-24) -->

- 제주특별자치도 코드 조회: 10건 응답 확인.
- 제주특별자치도 제주시 동명 저수지: 최근 30일 30건, 2026-07-24 저수율 61.4% 응답 확인.
- `facCode`가 없는 잘못된 수위 요청은 HTTP 400 및 필수값 안내를 반환함을 확인.
