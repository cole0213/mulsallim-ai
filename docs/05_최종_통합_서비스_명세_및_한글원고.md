# 물살림 AI 최종 통합 원고

> 이 문서를 서비스개발 참가신청서·발표자료·웹 화면의 단일 기준으로 사용한다. 기존 `02`, `04` 원고는 초안이며, 제출 시에는 본 문구를 우선한다.

## 1. 서비스 기본정보

- 공모분야: 서비스개발 / 안전강화
- 서비스명: **물살림 AI - 가뭄 전환점 예측 및 공동 절수 시나리오 서비스**
- 서비스 형태: 공개용 웹 랜딩·현장 조회 화면 + 관리자용 운영 관제 대시보드
- 서비스 URL: 로컬 시연 `http://localhost:4182/operations-live.html`, 운영 관제 `http://localhost:4182/control-center.html`
- 개발기간: 2025.11~2026.07 (공모전 운영기간 내 서비스 구체화)

## 2. 서비스 개요

물살림 AI는 한국농어촌공사 농업용저수지 수위정보를 현장 담당자와 농업인이 이해하고 행동할 수 있는 정보로 바꾸는 웹 서비스이다. 사용자는 저수지명과 지역을 검색해 시설코드를 확인하고, 기간별 실제 관측 수위·저수율을 조회한다. 서비스는 최신 저수율, 관측기간 변화, 설명 가능한 위험 단계, 0%·10%·20% 공동 절수 시나리오를 한 화면에서 제공한다.

핵심은 단순 수위 조회가 아니라 “언제 절수를 검토할지”, “절수 수준에 따라 기준선 도달 시점이 어떻게 달라지는지”를 같은 근거로 협의하도록 돕는 것이다. 모든 판단은 공식 경보나 급수 지시를 대체하지 않는 의사결정 보조 정보로 표시한다.

## 3. 추진 배경 및 문제 정의

농업용 저수지의 저수율은 공개되어 있으나, 현장에서는 수치 자체보다 변화 속도와 다음 행동이 필요하다. 농업인은 관개 가능 여부를, 관리자는 점검·급수 조정 우선순위를 빠르게 판단해야 한다. 기존 정보는 조회 중심이라 동일 수치를 보고도 사용자별 해석과 대응시점이 달라질 수 있다.

물살림 AI는 KRC 원자료를 그대로 출발점으로 하되, 관측기간 변화와 기준선 도달 시나리오를 시각화해 ‘공동 절수 전환점’을 논의할 수 있게 한다. 공공데이터의 활용 가치를 단순 공개에서 지역 농업용수 안전 의사결정으로 확장한다.

## 4. 주요 기능 및 구현 내용

1. **KRC 실시간 원자료 연동**: 서버 환경변수에만 인증키를 보관하고, `reservoircode`로 저수지 코드 검색, `reservoirlevel`로 일별 `check_date`, `water_level`, `rate`를 조회한다. 실제 탑정저수지(충청남도 논산시, 시설코드 4423010045) 관측 데이터 연동을 확인했다.
2. **공개용 랜딩·조회 화면**: 저수지명/지역 검색, 기간 선택, 저수율 추세 그래프, 최신 관측일, 원자료 건수를 제공한다. 데이터가 없거나 API 오류가 나면 성공으로 보이지 않고 오류 상태를 표시한다.
3. **운영 관제 대시보드**: 최신 저수율, 7일 변동, 단계별 권고, 근거 목록, 새로고침 기능을 제공한다. 관리자가 데이터·판단·권고를 같은 화면에서 확인한다.
4. **공동 절수 시나리오**: 관측기간의 하락 속도가 유지된다는 가정 아래 저수율 25% 기준선까지의 시간을 0/10/20% 절수 조건으로 비교한다. 하락 추세가 없으면 추정치를 만들지 않고 ‘하락 관측 없음’으로 표시한다.

## 5. KRC 공공데이터 활용 적정성

필수 공공데이터는 한국농어촌공사 ‘농촌용수 저수지 수위정보 조회’ OpenAPI이다. 코드조회 API의 `fac_name`, `county`, `fac_code`로 대상 저수지를 식별하고, 수위조회 API의 `check_date`, `water_level`, `rate`로 관측 추세를 계산한다. 저수지별 최대 365일 조회 범위를 준수한다. API 키는 브라우저나 저장소에 노출하지 않고 백엔드 환경변수로만 관리한다.

## 6. AI 활용성 및 검증 계획

MVP는 설명 가능한 규칙 기반 판단과 시나리오 엔진으로 구현한다. 저수율 35% 이하를 주의, 35~50%를 관심, 50% 초과를 안정으로 표시하되 이는 공적 경보가 아닌 화면 내 보조 분류임을 명시한다. 최신 저수율, 기간 변동, 하락 속도, 데이터 최신성을 근거로 제시하여 사용자가 결과를 검토할 수 있다.

고도화 단계에서는 저수지별 일별 데이터 365일 단위 누적 후 시계열 교차검증을 수행한다. 기준모형(전일값 지속)과 Gradient Boosting/Prophet 계열을 MAE·MAPE로 비교하고, 이상 하락 탐지는 Isolation Forest와 수동 검토 표본의 정밀도·재현율로 검증한다. LLM은 수치 산출자가 아니라 검증된 결과의 쉬운 설명에만 사용한다.

## 7. 차별성·사업성·확장성

기존 저수율 서비스가 조회·예측 제공에 집중한다면, 물살림 AI는 관측값을 ‘공동 절수 전환점’과 ‘사용자별 행동 문장’으로 연결한다. 초기에는 KRC 물관리 업무 보조 모듈로 5~10개 저수지를 대상으로 시범 운영하고, 이후 지자체 농업용수 담당자·농업인 단체에 지역별 대시보드로 확장한다. 수익화는 공공기관용 관리 화면, 지역 맞춤 보고서, 운영 컨설팅을 조합하되 공공 원자료 자체를 유료화하지 않는다.

## 8. 기대효과

- 농업인: 수치 해석 부담을 줄이고 관개 계획·절수 협의의 근거 확보
- 관리자: 관측 변화 기반의 점검·협의 우선순위 확인
- 공공: KRC 공공데이터를 안전강화 의사결정에 재사용하고 활용사례 축적
- 기술: 원자료, 판단근거, 한계 고지를 함께 제공하는 책임 있는 AI 서비스 구현

## 9. 발표 시연 순서

1. 공개 화면에서 ‘탑정·충청남도’를 검색해 시설코드를 선택한다.
2. 실제 일별 저수율 그래프와 최신 관측일을 제시한다.
3. 운영 관제에서 7일 변동과 권고 근거를 확인한다.
4. 0/10/20% 절수 시나리오를 비교하고, 이는 공식 지시가 아닌 협의용 보조 판단임을 설명한다.
