# 물살림 AI 사용자용 최종 경로

## 핵심 요약

사용자 시연과 실제 반복 사용은 기술 설명 중심의 기존 화면이 아니라, 지역 선택·관심 저수지 재진입·오늘의 확인 순서를 중심으로 한 아래 경로를 사용한다.

## 최종 사용자 경로

- 시작 랜딩: `http://localhost:4182/mulsallim-user-final.html`
- 실제 서비스: `http://localhost:4182/mulsallim-service-ux.html`

## 사용자 경험 개선

- 첫 화면에서 시·도·시·군·구 선택으로 바로 시작한다.
- 관심 저수지는 브라우저에 저장되어 재방문 시 시작 화면에 나타난다.
- 서비스 화면은 긴 소개를 제거하고 지역 선택, 오늘의 확인 순서, 판단 근거, 행동·공유 흐름을 우선한다.
- AI 모델 검증·기술 방법은 일반 사용자의 핵심 과업을 방해하지 않도록 접어 둔다.
